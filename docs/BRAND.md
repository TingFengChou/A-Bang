## 2. 吉祥物：阿幫

- **角色**：一隻圓滾滾的**台灣藍鵲**（台灣特有種），熱心的鄰居型角色。
- **App 名稱**：**Abang**（2026-11-20 Austin 決定；不加 Bot，像 Grok、Claude 一樣名字就是那個 agent）。吉祥物與對話裡仍叫「阿幫」。
- **藍鵲在 App 裡面**：首頁、對話頭像、浮動阿幫、查詢中與完成的表情。**App 圖示與啟動畫面不放藍鵲**，用 Λ 標誌（§2.1）。
- **agent 感**（2026-11-20）：**冠羽**（招牌；三根往後梳、前長後短、前後深藍中間亮藍（有層次），不加光點。Austin：「鳥類最漂亮的應是他的冠」）、耳麥（左耳罩與麥克風，隨時待命、跟小幫手通話）、右眼 HUD 鏡片（查詢中顯示進度條、完成時打勾）、背包天線。不戴帽子。
- **招牌配件**：
  - 往後梳的冠羽（取代原本的鴨舌帽）；耳麥與 HUD 鏡片
  - 小背包，上面的徽章代表「工具包」：交通、防詐、開業、旅遊。每多一個工具包，就多一枚徽章，呼應平台架構
- **個性**：熱心、講話直接、先講重點；有一點台味但不油、不裝可愛。
- **表情**（`public/brand/`）：

| 檔案 | 表情 | 使用時機 |
|---|---|---|
| `abang-default.svg` | 揮手 | 首頁、歡迎畫面、一般狀態 |
| `abang-think.svg` | 查詢中 | 工具呼叫中、載入中 |
| `abang-happy.svg` | 開心 | 查詢完成、任務完成 |

修改吉祥物或圖示請改 `scripts/build-brand.py` 後執行 `python3 scripts/build-brand.py`，再執行 `node scripts/build-icons.js` 產生圖示與啟動畫面 PNG（網頁、Android、iOS），不要手改 SVG 或 PNG。CI 會重跑 `build-brand.py` 檢查 SVG 與產生結果一致。

### 2.1 App 圖示：Λ 標誌

2026-11-21 產品負責人決定：App 圖示不用藍鵲，改用比較有科技感的標誌（定稿「C2」）。**圖示是 Λ 標誌，藍鵲是 App 內的吉祥物**，兩者不混用。

- **造型**（畫布 512）：品牌青綠漸層底（左上深、右下亮）＋中下方光暈；亮白薄荷色的 **Λ**（Abang 的 A，圓頭粗線）；Λ 中間一顆**琥珀色發光核心**（外面一圈淡光圈）；外面**一圈軌道**（淡線，右上一段亮弧）。
- **顏色**：底 `#0B3B39` → `#0F766E`（品牌青）→ `#14A396`；光暈 `#5EEAD4`；Λ `#CCFBF1` → `#FFFFFF`；軌道 `#99F6E4`（淡）與 `#CCFBF1`（亮弧）；核心 `#FBBF24`（鈕扣黃）、光圈 `#FDE68A`。

| 檔案（`public/brand/`） | 用途 |
|---|---|
| `icon.svg` | 圓角版：PWA 圖示（192／512）、favicon（同步到 `public/icons/icon.svg`）、Android 舊版圖示、啟動畫面置中的圖示 |
| `icon-square.svg` | 方形不透明：iOS App 圖示（1024，系統自己套圓角）、PWA maskable、apple-touch-icon、Android 舊版圓形圖示 |
| `icon-fg.svg`、`icon-bg.svg` | Android 自適應圖示：前景只有 Λ＋核心＋軌道（縮成 2/3，離中心最遠約 26dp，在 66dp 安全區內，圓形與各種遮罩都裁不到）；背景是漸層＋光暈（對齊露出的中間 72dp，所以遮罩裁出來和 iOS 圖示一樣）。iOS 18 深色（透明底，標誌本來就是亮色，不換色）與著色（灰階，Λ 最亮）圖示也由前景放大 1.5 倍產生 |
| `icon-mono.svg` | 單色剪影（只有 Λ＋核心，沒有軌道）：Android 13+ 主題圖示 `ic_launcher_monochrome`、Android 通知小圖示 `ic_stat_abang`（狀態列 24dp） |

啟動畫面：淺色底 `#F4F6F5`、置中圓角圖示、下方 Abang 字樣（品牌青）；Android 12+ 系統啟動畫面也是圓角圖示（`splash_icon`，白色的 Λ 單獨放在淺色底上看不到）。

不要做的事：不要把藍鵲放回圖示或啟動畫面；不要改 Λ 的比例、拿掉核心或軌道（小尺寸軌道會變淡是正常的）；不要在圖示上加字。

### 不要做的事

- 不要改成熊或其他動物（避開觀光署吉祥物「喔熊」等既有角色）
- 不要拿掉冠羽、耳麥或背包（辨識度來源）
- 不要拉伸變形、不要改主色
- 不要讓阿幫說出保證性話語（例如「這一定安全」），角色也要遵守護欄

## 4. 語氣

| 要 | 不要 |
|---|---|
| 先講結論：「307 再 3 分鐘到。」 | 「根據系統查詢結果顯示，307 公車預計將於…」 |
| 稱呼使用者用「您」，正式但親切：「要我在車快到時提醒您嗎？」（ADR-0023，2026-11-29 起全站） | 「你」、「親」、「大大」 |
| 口語、短句、台灣用語 | 網路流行語堆疊、過度撒嬌 |
| 適量台語詞：「報你知」（台語慣用語，是稱呼「您」的唯一例外，只用在口號） | 整句台語或刻意的台灣國語 |
| 不確定就說：「這個我查不到，建議打 165 確認。」 | 臆測或保證 |
| 對長輩友善：字大、步驟清楚 | 縮寫、英文術語 |

## 5. 商標與註冊

- 「阿幫」是常見暱稱，**純文字商標可能較難核准**。建議以「阿幫＋藍鵲圖形」申請**組合商標**，並另申請圖形商標（2026-11-21 起 App 圖示是 Λ 標誌：上架用的圖形是 Λ 標誌，要不要一併申請請營運單位與法務決定）。
- 建議類別：第 9 類（軟體、App）、第 35 類（商業管理與廣告）、第 42 類（軟體服務、SaaS）；若與電信服務結合，評估第 38 類。
- 正式使用前查：智慧局商標檢索、網域（abang 相關）、App Store／Google Play 名稱、GitHub 組織名稱。
- 吉祥物正式設計完成後，著作權歸屬（委託設計合約）要寫清楚。
