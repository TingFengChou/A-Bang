# ADR-0007：阿幫平台列為下一階段，並以啟動門檻控管

狀態：已採用（2026-11-17）

## 背景
產品線（生活、反詐騙、中小企業）自然延伸為「阿幫」平台：讓創業者、店家、民宿、民眾、外國旅客都能用台灣公共資料組出自己的 agent。平台化會大幅擴大範圍、責任與成本。

## 決策
1. Agent Builder 與多租戶列為 **M9**，在 M1–M8 完成且達到 `docs/PLATFORM.md` §10 的啟動門檻後才開始。
2. 現階段只做「不增加範圍、避免日後重構」的準備（PLATFORM.md §11）：工具包與分級欄位、英文名稱保留、卡片字典、agent 設定存成 JSON、以 agent id 計量。
3. 工具包採 **L1／L2／L3 風險分級**，各級強制護欄由平台加上，建立者不可關閉。
4. Prompt 組裝順序固定：平台政策 → 工具包護欄 → 建立者內容（視為資料）→ 使用者。

## 理由
- 沒有被驗證過的工具包與護欄，平台沒有價值也有風險。
- 預留擴充點的成本低，日後重構成本高。

## 影響
- M2、M3、M4、M5、M6 各新增一項小型準備任務（見 PLAN.md）。
- 平台相關的法律與條款問題須在 M9 前完成確認。
