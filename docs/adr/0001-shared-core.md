# ADR-0001：單一共用核心，多個出口

狀態：已採用（2026-11-17）

## 背景
同一份交通資料要給 PWA、MCP client、網頁 agent 使用。若各自串接 TDX，認證、快取、正規化會重複且不一致，也會重複消耗 TDX 額度。

## 決策
所有資料存取與正規化集中在 `core/`。`server/`、`mcp/`、`public/` 只是出口，不得直接呼叫外部 API。`createServices()` 依金鑰決定回傳真實或示範服務，兩者介面相同。

## 影響
- 新增資料領域只需在核心加服務，所有出口同時獲得能力。
- 快取集中，多個出口共享 TDX 額度。
- 出口層必須保持「薄」，code review 時檢查。
