# ADR-0022：地名的同音字容錯

- 狀態：**採納 1＋C**（2026-11-28，Claude 與 Antigravity 第二、九、十輪；不加依賴。B、A 等實機錯字量再決定，要 Austin）
- 相關：ADR-0015（裝置端的聽與看）、ADR-0016（阿幫問你：不默默套用）、M14-01 語音問阿幫

## 背景

語音問阿幫已經上線（M14-01：只在手機上辨識）。辨識會把地名換成同音字，例如：

| 說的 | 辨識成 |
|---|---|
| 新莊 | 新裝 |
| 板橋 | 搬橋 |
| 汐止 | 夕止 |
| 內湖 | 內壺 |
| 景美 | 警美 |

現在有的：
- `normalizeAsk`：固定的錯字表（車戰→車站、機常→機場）。只收「有明確上下文」的字，避免改到正常句子。
- 內建地標的別名（北車、竹科）。
- #213 的關卡：亂打的名稱不會白燒 TDX 額度。

缺的是：**沒在錯字表裡的同音字**。結果是「查不到這個地點」，或更糟——被當成別的地方。

## 決定（草稿）

### 1. 先從源頭減少錯字：把地名交給手機的語音辨識（不加依賴）
- **iOS**：`SFSpeechRecognitionRequest.contextualStrings`
- **Android 13+**：`RecognizerIntent.EXTRA_BIASING_STRINGS`（較舊的版本沒有，就照舊辨識）
- 給的字串：
  - 內建地標名稱與別名
  - 使用者的常用地點名稱、預設地區
  - 附近的車站與站牌名（有定位時）
- 上限約 100 個（系統建議的範圍），只在手機上，不送伺服器。超過時的截斷順序（Antigravity 第十輪）：常用地點、預設地區 → 附近的車站與站牌 → 全國地標（別名最後）。
- 風險（Antigravity）：提示太多可能把一般句子轉成地名（over-biasing），所以有上限、只給地名；系統採不採納提示看各家語音引擎，Android 13 以下沒有這個參數，沒定位時少了附近站牌——第 2 點是這些情況的保底。
- 這一步不改任何文字，只是讓辨識器更容易聽對。

### 2. 真的聽錯了才容錯，而且只在「找不到地點」時
- 已經認得的字一律不動。只有 `find_place`／地名解析找不到時，才在一個**有限的候選集合**裡找最像的：
  - 內建地標與別名
  - 365 個鄉鎮市區（T-HOMEAREA 的資料）
  - 車站名
- **絕不默默套用**（ADR-0016）：出題「你是說「新莊」嗎？」，選項第一個標「猜的」，另一個選項是「都不是，我再說一次」。
- 只比字數相同的候選；三個字以上要至少一個字完全一樣（「新裝」→「新莊」：「新」相同），兩個字的允許兩字都同音（「半喬」→「板橋」，Antigravity：兩字都聽錯時才救得到；候選集合有限，風險可控），避免猜得太遠。
- 好幾個候選：預設地區與常用地點所在縣市的優先，其次離現在位置近的，最多列 3 個，另附「都不是，我再說一次」。
- **刻意的取捨**：聽錯成另一個真的地名（例如冷門的同音地名）不會觸發容錯——那時阿幫查得到，就照那個地名回答，行程卡上的起訖點看得出來。

### 3. 怎麼判斷「同音」
| 選項 | 作法 | 代價 |
|---|---|---|
| A | 加中文轉注音的套件，執行時算 | **新增依賴（停止條件）** |
| B | 一次性產生候選集合的注音表，存成 `core/data/place-zhuyin.json`，執行時只查表 | 產生時要工具（也算依賴，只在開發時用）；地標增加時要重跑 |
| C | 手寫小型「常見同音字」對照表（莊／裝、橋／喬、湖／壺…），只用在候選集合 | 不加依賴；涵蓋不完整，要靠實機語音回報慢慢補 |

**決定：先做 1＋C**（Claude 建議、Antigravity 第十輪同意）。
- 1 不加依賴，從源頭就能減少大部分錯字。
- C 收實際碰到的錯，不加依賴。
- 同音比對抽成單一查詢介面（`sameSound(a, b)`），日後要換成 B 的預編譯注音表時只換這一個函式。
- 實機一陣子後，看錯字回報的量，再決定要不要走 B（要 Austin）。

## 驗收
- 語音說「新莊」「板橋」「汐止」「內湖」「景美」：iOS 與 Android 13+ 辨識正確率提升（實機，要 Austin）。
- 打字「去新裝」：出題「你是說「新莊」嗎？」，第一個選項標猜的；按了才排行程。
- 打字「去新店」（正常）：不出題、不改字。
- 打字「去宇宙」（候選集合裡沒有像的）：照舊說找不到，不亂猜。
- 多個候選撞在一起：排序合理、最多 3 個、保留「都不是，我再說一次」（Antigravity 第十輪）。
- 沒有定位權限、Android 13 以下：語音照常運作不報錯，聽錯時落回第 2 點容錯。
- 提示超過 100 個：常用地點與附近站牌不會被全國地標擠出名單。

## 後果
- 好處：語音問阿幫最常見的失敗（地名聽錯）大幅減少；就算錯了也不會默默去錯地方。
- 成本：
  - 原生外掛 `AbangVoice` 要多收一個參數。
  - 容錯會多一題「你是說…嗎？」，只在找不到時才出現。
- 不做：一般句子的錯字修正（交給模型或判斷層）、台語發音轉華語字。
