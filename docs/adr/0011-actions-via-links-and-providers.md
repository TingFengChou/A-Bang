# ADR-0011：導航、訂票、叫車以「官方連結＋provider adapter」實作

狀態：已採用（2026-11-17）

## 背景
Austin 希望阿幫不只給建議，還能帶使用者去做：導航（站牌座標）、台鐵／高鐵買票、叫車（先保留 Uber 串接，YouBike 繼續保留）。直接在站內付款或代叫車需要業者合作、金流與個資責任，超出現階段範圍。

## 決策
1. **導航**：所有點位附 `nav`（Google／Apple Maps 深層連結），不做站內逐步導航。「出發時機」由即時到站＋步行時間計算。
2. **訂票**：使用 TDX「導訂票」產生具時效的官方訂票連結（自動帶入車次、日期、張數），付款與個資在官方網站完成。需 TDX 權限，未取得前 tool 回傳清楚的「尚未開通」錯誤。
3. **叫車**：`core/providers/ridehail/<provider>.js` adapter，介面 `{ id, name, link({ from, to }), estimate?({ from, to }) }`；先做 Uber 深層連結。估價需業者合作，之前以距離＋路況估算並標「估算」。
4. **外部 MCP**：TDX 官方 MCP 等外部 MCP 經 `core/providers/mcp-client.js` 包成本專案 tool，討論串標示 `server`。
5. 以上行動類 tool 為 **L2**：產生連結前必須讓使用者確認（卡片確認視窗或模型先問），不代替付款、不收集個資。

## 影響
- 不需要金流與業者合約即可上線；體驗多一次跳轉。
- 之後與台鐵／高鐵／叫車業者合作時，只需替換 provider 實作，tool 介面不變。
