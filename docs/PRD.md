# PRD — 阿幫（A-Bang）

版本：v0.4（2026-11-17）　負責人：Austin（TingFengChou）

## 1. 問題

台灣交通開放資料（TDX）品質好、涵蓋全國，但民眾要查「公車還要多久、要不要改騎 YouBike、塞車時該搭什麼」得在好幾個 App 之間切換、自己比較。AI 助理流行後，民眾習慣用一句話問，但現有助理沒有可靠的台灣即時交通資料，也不會依「我現在的狀況」幫忙做決定。

## 2. 目標

1. 一組**完整、可靠的台灣交通 MCP tools**，任何 AI agent（含 Claude）都能使用。
2. 阿幫依「**MCP 回來的資料＋使用者狀態**」做出**最佳建議**，且過程看得懂、看得到（小幫手討論串＋決策圖）。
3. 民眾不需要 Claude 帳號，打開網頁就能用；建議後能直接**行動**（導航、提醒、訂票、叫車）。

## 3. 使用者

| 使用者 | 情境 | 入口 |
|---|---|---|
| 一般民眾 | 通勤、出遊、趕時間時快速決定怎麼走 | 網頁 agent（手機） |
| Claude 使用者 | 在 Claude 裡順手問交通 | 遠端 MCP 自訂連接器 |
| 開發者／其他 agent | 把台灣交通能力接進自己的產品 | MCP（stdio／HTTP）、REST |

## 4. 本階段範圍：阿幫・生活（交通）、網頁優先

### 4.1 查詢能力（MCP tools，詳見 `MCP_TOOLS.md`）

- 公車：路線搜尋、路線即時到站（含路線圖座標）、附近站牌、站牌到站 ✅
- YouBike：附近站點可借／可還 ✅
- 台鐵、高鐵：時刻表、車站、票價 ✅；導訂票連結 📝
- 捷運：車站、即時到站看板 📝
- 地點：地名轉座標 📝
- 路況：即時路況、道路事件 ✅；國道客運 ✅
- 行程規劃：從 A 到 B（步行、YouBike、公車直達、軌道、客運、叫車），由決策引擎排序 📝

### 4.2 決策（ADR-0010）

- 依資料與使用者狀態排序方案：總時間、等車、走路、費用、淋雨、體力、塞車風險。
- 狀態：趕時間、塞車中、下雨、帶行李、想省錢、少走路；抵達時間限制。
- 狀態來源標示：自動判斷（天氣、路況工具）、你說的（對話）、你選的（點選）。
- 範例：下雨 → 有遮蔽的公車；塞車 → 台鐵／高鐵；10 點前要到 → 排除會遲到的方案。

### 4.3 體驗（`UX.md`）

- 小幫手討論串：阿幫點名 @公車、@YouBike、@天氣…，各自一句話回報（含 MCP 來源）。
- 決策圖：資料流向阿幫 → 狀況 → 方案比較 → 最佳方案亮起；狀況可點選即時重算。
- 結論卡片：建議方案、分段時間條、備案、即時倒數、行動按鈕。
- 淺色、手機優先、吉祥物阿幫（台灣藍鵲）；輕量 3D 轉場。

### 4.4 行動

- 導航：開啟 Google／Apple 地圖到站牌或車站。
- 提醒：到站前、出門時間（裝置端提醒）。
- 訂票：台鐵、高鐵官方訂票頁（自動帶入班次與張數，需 TDX 導訂票權限）。
- 叫車：Uber 深層連結（估價待合作）。

### 4.5 出口

- 網頁 agent：Claude API（預設 `claude-haiku-5-5`）；無 Key 時示範模式。
- 遠端 MCP：`/mcp` ✅、MCP Apps 卡片 📝。

## 5. 非目標（本階段）

原生 App、站內付款購票、多段轉乘最佳化、天氣／AQI 等非交通查詢（天氣僅作為決策輸入，規劃中）、使用者帳號、Builder 與多租戶（M9）。

## 7. 成功指標

| 指標 | 目標 |
|---|---|
| tools 在真實資料下成功率 | ≥ 99% |
| 網頁 agent 第一個事件（P50） | ≤ 1 秒；完整建議 ≤ 5 秒 |
| 建議被採用（點擊導航／訂票／提醒） | ≥ 30% |
| 使用者改變狀況後仍採用建議 | 追蹤 |
| 單次對話 TDX 呼叫（P90） | ≤ 8 |
| 單次對話模型成本 | ≤ NT$0.3（Haiku） |

## 8. 風險

| 風險 | 對策 |
|---|---|
| 部分 TDX 端點未實測（站牌到站、形狀、捷運、路況、客運、導訂票） | M1 先錄製真實回應 |
| TDX 額度 | 快取、限流、Redis（M6） |
| 建議錯誤造成損失 | 決策透明（理由＋來源）、行動前確認、標示「估算」 |
| 模型成本被濫用 | 每 IP／每日上限、全站預算、超額降級示範模式 |
| 競品（TDX 官方 MCP、中華電信防詐守衛、LINE AI 代理平台） | 差異化在組合工具、決策、互動體驗（`CONTEXT.md`） |
| 位置隱私 | 不落地、不寫 log |
